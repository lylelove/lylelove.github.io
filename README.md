## 🛠️ 开发

### 本地开发
```bash
# 克隆仓库
git clone https://github.com/lylelove/lylelove.github.io.git

# 进入目录
cd lylelove.github.io

# 启动本地服务器
python -m http.server 8000
# 或者使用 Node.js
npx http-server

# 访问 http://localhost:8000
```

### 部署到GitHub Pages
1. Fork 这个仓库
2. 在仓库设置中启用 GitHub Pages
3. 选择源分支为 `main`
4. 配置自定义域名（可选）
